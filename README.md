# Kraftly – Driftstatus

En liten statisk sida som visar Kraftlys driftstatus och de senaste avbrotten.

## Kom igång

Ingen byggkedja behövs — öppna `index.html` i webbläsaren, eller kör en enkel server:

```bash
python3 -m http.server 8000
```

## Så arbetar vi

1. Utgå alltid från färskt `main`: `git switch main && git pull`
2. Skapa en kort gren: `git switch -c fix/beskrivande-namn`
3. Committa med conventional commits: `fix: öka kontrast på headerlänkar`
4. Öppna en pull request och fyll i mallen
5. Minst en kollega granskar innan merge
6. Squash merge och radera grenen
